# Socioryx API Skill

Use the Socioryx API to access content marketing services, portfolio, and AI audit tools.

## Endpoints
- `GET https://socioryx.com/.well-known/api-catalog` — API catalog (RFC 9727)
- `POST https://socioryx.com/api/contact` — submit contact
- `POST https://socioryx.com/api/audit/report` — request audit
- `GET https://socioryx.com/api/uptime` — health
- `GET https://socioryx.com/.well-known/ai-catalog.json` — ARD catalog
- `GET https://socioryx.com/.well-known/mcp/server-card.json` — MCP server card

## Auth
See `https://socioryx.com/auth.md` and `/.well-known/oauth-protected-resource` for registration.
